# Portfolio description

Pushup Verifier is a Python computer-vision project using MediaPipe and OpenCV to measure joint angles and assess pushup sequences from video. Across ten single-person recordings, I built a reproducible extraction and replay pipeline, compared immediate and temporal decisions, and investigated failures caused by framing, uncertain landmarks, and missed starting positions. Experimental logic separates movement completion from form assessment and explicitly reports partial starts and missing alignment evidence. On a fresh mixed-set video evaluated without retuning, the system completed all five movements and matched the expected full–shallow–full–shallow–full decision sequence. The project includes an annotated demo, documented experiments, and 52 automated tests; broader validation across people and camera setups remains future work.
