# Portfolio description

Pushup Verifier is an ongoing computer-vision project built with Python, MediaPipe, and OpenCV that measures joint angles and evaluates pushup sequences from video. Across nine single-person pilot recordings, I compared immediate and temporal decisions, investigated tracking failures, and developed experimental logic that separates movement completion from form assessment while explicitly reporting uncertain alignment and partial starts. On one follow-up clip, this recovered all five completed movements, with three accepted and two left unassessable rather than overstating confidence. The project includes reproducible extraction and replay, annotated video, documented failure analysis, and 52 automated tests. Validation of the latest changes on fresh recordings remains the next step.
