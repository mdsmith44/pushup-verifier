# Portfolio description

Pushup Verifier is an ongoing computer-vision research project that uses Python, MediaPipe, and OpenCV to measure joint angles and evaluate conventional pushup sequences from video. I am developing a reproducible pipeline for pose extraction, annotated video, and rule-based repetition assessment, with explicit handling of uncertain observations. Initial pilot experiments compare immediate threshold decisions with temporal smoothing and persistence: the immediate method matched manual counts on full and shallow repetition clips, while the temporal and occlusion tests exposed missed transitions and overly sensitive dropout handling. The project emphasizes transparent failure analysis, testable software, and the translation of physical procedures into measurable visual rules; independent validation is the next stage.
